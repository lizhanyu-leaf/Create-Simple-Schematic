English (英文):

>## Simple Schematic (Standalone)
>Do you enjoy the convenient "Simple Schematic" feature from the [Create: The Brass Concerto](https://www.curseforge.com/minecraft/modpacks/create-the-brass-concerto) modpack, but prefer not to be tied down by the rest of the pack?
>
>This mod is the solution! With official permission from the original modpack author, this feature has been completely extracted and refactored into a standalone mod.
>
>**Features**:
>
>- **Standalone Operation**: Requires only Create as a dependency; no need for Andesite Abound.
>
>- **Core Gameplay**: Retains the core mechanics of "Simple Schematic," focusing on simplifying the building and material preparation process in Create.
>
>- **Lightweight**: Focuses on a single feature with no bloat code, ensuring better compatibility.
>
>**Acknowledgments**:  
>Thanks to [Apertyotis](https://github.com/Apertyotis) for the original idea and generous permission, allowing this great feature to benefit more players.
